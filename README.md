# Study Focus｜我的学习专注台

一个轻量的中文学习专注网页，提供专注计时、休息提醒和学习任务清单。

这是一个学习练习项目，用于实践网页开发、浏览器本地存储和 GitHub 项目发布。

## 在线体验

[打开学习专注台](https://luck8532.github.io/study-focus/)

直接用浏览器打开，无需注册或安装。

## 功能

- 专注模式：20 分钟倒计时。
- 休息模式：5 分钟倒计时。
- 支持开始、暂停、继续和重置。
- 计时结束播放提示音。
- 自定义背景颜色，刷新后保留选择。
- 添加学习任务，勾选或取消完成状态。
- 自动保存任务内容及完成状态。

## 使用方法

1. 选择“专注 20 分钟”或“休息 5 分钟”。
2. 点击开始按钮启动计时。
3. 需要时暂停、继续或重置。
4. 在“今天想学什么？”中输入任务，点击“添加任务”。
5. 完成任务后，勾选任务左侧的复选框。

## 数据保存与限制

- 任务和背景颜色使用 localStorage（浏览器本地存储）保存。
- 数据保存在当前设备的当前浏览器中，不会自动同步到其他设备。
- 清除网站数据可能导致已保存的任务和颜色设置丢失。
- 刷新页面会重置计时进度，任务和颜色设置会保留。
- 浏览器或系统限制可能影响后台计时更新和结束提示音。

## 技术实现

- HTML（网页结构）
- CSS（页面样式）
- JavaScript（交互逻辑）
- GitHub Pages（静态网页托管）

页面代码集中在 `index.html`，无需后端服务器。
